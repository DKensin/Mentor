6. Hàm strcpy dùng để copy 2 mảng data, ví dụ đoạn chương trình dưới đây:
	char str1[20] = "C programming";
	char str2[20];

  	// copying str1 to str2
  	strcpy(str2, str1);

  	puts(str2); // C programming
	
Yêu cầu: viết hàm string_copy (user-defined) tương tự như hàm strcpy (build-in).
Expectation:
	string_copy(str2, str1);
	printf("%s\n", str2);	// C programming
